# Overview

Classic Mode is the definitive bingo experience.

It preserves the familiar rules of traditional bingo while elevating the presentation, emotional pacing, and social interaction expected from a modern multiplayer game.

Classic Mode is the foundation upon which every future game mode is built.

If a player understands Classic Mode, they should immediately understand the spirit of the entire game.

---

# Design Goals

Classic Mode exists to achieve five objectives.

- Preserve the identity of traditional bingo.
- Create emotional tension throughout the match.
- Encourage memorable social moments.
- Reward every player's time.
- Deliver a satisfying conclusion regardless of outcome.

---

# Core Philosophy

Classic Mode should feel familiar.

Players should never think:

> "This isn't bingo anymore."

Instead they should think:

> "I've never played bingo like this before."

That distinction is critical.

We are modernizing the experience—not replacing the game.

---

# Match Structure

Every Classic match follows the standard Match Flow.

```
Lobby

↓

Card Reveal

↓

Countdown

↓

Early Game

↓

Mid Game

↓

Critical Stage

↓

Heartbeat (Optional)

↓

Winner

↓

Rewards
```

---

# Match Objective

Receive a bingo card.

Mark called numbers.

Complete the required winning pattern before every other player.

Claim victory.

Simple.

Everything else enhances this experience.

---

# Card Ownership

A player's card should feel personal.

The reveal animation should create immediate attachment.

Players should instinctively think:

> "This is my card."

Throughout the match, the card becomes the center of the player's attention.

---

# Number Calling

Each number draw should feel important.

The announcer should never sound robotic.

Presentation should communicate excitement naturally.

The pacing should allow players enough time to:

- Hear the number.
- Locate it.
- Mark it.
- Observe other players' reactions.

The game should never feel rushed.

Likewise, it should never feel slow.

---

# Match Pacing

Classic Mode is designed around gradually increasing tension.

## Early Game

Everyone is optimistic.

Players quickly begin marking numbers.

Hope is high.

Mistakes are rare.

---

## Mid Game

Players begin comparing progress.

Near-complete rows appear.

Excitement increases.

Competition naturally develops.

---

## Critical Stage

Multiple players approach victory.

Every draw becomes meaningful.

The atmosphere changes.

Players naturally become quieter and more focused.

---

## Heartbeat Stage

If multiple players are within one number of victory, Heartbeat Mode may activate.

Heartbeat is intentionally rare.

Its purpose is to transform an already exciting finish into an unforgettable one.

---

# Winning

Winning should feel earned.

Not because players controlled luck.

But because they remained engaged throughout the match.

The winning sequence should feel celebratory rather than abrupt.

The match should pause briefly to recognize the achievement before transitioning into rewards.

---

# Losing

Defeat should never feel discouraging.

Players should immediately receive:

- Progression
- Recognition
- Match highlights
- Personal achievements
- Motivation to continue

The goal is:

"I almost had it."

Not:

"I wasted my time."

---

# Social Experience

Classic Mode should encourage interaction without requiring it.

Examples include:

- Reactions
- Friendly celebrations
- Spectating the winner
- End-of-match acknowledgements
- Shared excitement during Heartbeat

The social layer should strengthen—not interrupt—the core gameplay.

---

# Success Criteria

A successful Classic Mode match should leave players feeling:

- The match was fair.
- Every number mattered.
- The ending was memorable.
- The game respected their time.
- They want to play again.

---

# What Classic Mode Is Not

Classic Mode is not designed to be:

- Highly strategic.
- Overly competitive.
- Mechanically complex.
- Fast-paced chaos.
- An action game.

Its strength lies in anticipation, emotional pacing, and shared moments.

Other game modes may introduce additional mechanics, but Classic Mode remains the purest expression of the game's identity.

---

# Future Expansion

Classic Mode should remain intentionally stable.

Future updates may improve:

- Presentation.
- Accessibility.
- Match polish.
- Visual themes.
- Audio.
- Social features.

However, the fundamental rules of Classic Mode should rarely change.

It serves as the benchmark against which every future mode is measured.

---

# Closing Statement

Classic Mode represents the heart of the game.

It demonstrates our belief that extraordinary experiences do not require complicated mechanics.

By combining timeless gameplay with thoughtful presentation, emotional pacing, and meaningful social interaction, Classic Mode transforms a familiar game into a memorable modern experience.

Every new game mode should begin by respecting what Classic Mode gets right before attempting to build upon it.

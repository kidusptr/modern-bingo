# Introduction

The Game Loop defines the repeating cycle that keeps players engaged.

Unlike the Match Flow, which describes everything that happens during a single match, the Game Loop describes why players continue returning to play another match.

Every feature in the game should strengthen one or more parts of this loop.

A healthy loop creates momentum.

A weak loop creates boredom.

---

# The Core Loop

```
Open Game
    ↓
Choose Mode
    ↓
Play Match
    ↓
Experience Excitement
    ↓
Earn Rewards
    ↓
Progress Account
    ↓
Unlock Content
    ↓
Customize
    ↓
Play Again
```

This is the heartbeat of the entire game.

Every completed cycle should naturally encourage the next.

---

# The Micro Loop

The Micro Loop occurs continuously during every match.

```
Number Drawn
      ↓
Player Reacts
      ↓
Player Marks Card
      ↓
Progress Updates
      ↓
Suspense Builds
      ↓
Next Number
```

This loop repeats dozens of times within a single match.

Each repetition should feel satisfying.

No draw should feel meaningless.

---

# The Emotional Loop

The game is designed around an emotional cycle rather than a mechanical one.

```
Curiosity
      ↓
Anticipation
      ↓
Hope
      ↓
Focus
      ↓
Suspense
      ↓
Adrenaline
      ↓
Celebration
      ↓
Satisfaction
      ↓
"I want one more match."
```

This emotional progression is more important than any individual feature.

Mechanics exist to support these emotions.

---

# The Progression Loop

Every match contributes to long-term growth.

```
Play
    ↓
Earn XP
    ↓
Complete Missions
    ↓
Unlock Rewards
    ↓
Customize Profile
    ↓
Increase Collection
    ↓
Play Again
```

Players should always feel they are moving forward.

---

# The Social Loop

Players create stronger memories when they play together.

```
Invite Friends
      ↓
Play Together
      ↓
Celebrate
      ↓
Share Stories
      ↓
Invite Again
```

The game should naturally encourage this cycle without forcing it.

---

# The Discovery Loop

Players should regularly encounter something new.

```
Play
    ↓
Discover Feature
    ↓
Experiment
    ↓
Master
    ↓
Discover Something Else
```

Examples include:

- New game modes
- Seasonal events
- Cosmetics
- Achievements
- Rare animations
- Dynamic match events

Discovery keeps the experience fresh.

---

# The Mastery Loop

Some players enjoy improving.

```
Play
    ↓
Learn
    ↓
Recognize Patterns
    ↓
Improve Decisions
    ↓
Feel More Confident
    ↓
Play Again
```

Although luck determines the outcome, familiarity should make players feel more comfortable and engaged over time.

---

# How the Loops Work Together

A successful session strengthens multiple loops simultaneously.

For example:

- The player enjoys the match (Emotional Loop).
- They earn XP (Progression Loop).
- They unlock a cosmetic (Discovery Loop).
- They celebrate with friends (Social Loop).
- They queue for another match (Core Loop).

No single loop should carry the entire experience.

Together, they create long-term engagement.

---

# Design Principles

Every feature introduced into the game should answer the following questions:

- Which loop does it strengthen?
- Does it encourage another match?
- Does it improve the emotional experience?
- Does it create memorable moments?
- Does it reward the player's time?

If the answer to all of these questions is "No," the feature should be reconsidered.

---

# Success Criteria

The Game Loop is successful when players naturally think:

- "One more match."
- "I almost had it."
- "I want to unlock that."
- "Let's invite someone."
- "I wonder what's next."

The desire to continue should come from enjoyment, not obligation.

---

# Closing Statement

The Game Loop is the engine that drives the entire experience.

Match Flow creates excitement.

Progression creates purpose.

Social play creates memories.

Discovery creates curiosity.

Together, they transform individual matches into a game that players want to return to again and again.

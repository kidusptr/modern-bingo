# Introduction

This document defines the rules that protect the identity of the game.

Unlike design guidelines or principles, these are absolute.

Whenever a feature conflicts with one of these non-negotiables, the feature must be redesigned or rejected.

The purpose of this document is not to limit creativity.

It is to ensure that every future addition strengthens the game instead of slowly changing it into something it was never meant to become.

---

# 1. The Spirit of Bingo Must Always Remain

No feature may replace the core identity of bingo.

Players should always recognize the familiar rhythm of:

- Receiving a card.
- Waiting for numbers.
- Marking matches.
- Building toward a winning pattern.
- Celebrating a completed card.

Modern mechanics should enhance this experience—not replace it.

---

# 2. Fairness Can Never Be Sold

Gameplay advantages must never be purchased.

Players may purchase cosmetics, personalization, or convenience features, but they must never be able to buy a higher chance of winning.

Skill and luck determine the outcome.

Never money.

---

# 3. Every Match Must Be Worth Playing

Players should never finish a match feeling that their time was wasted.

Whether they win or lose, every match should contribute toward long-term progression through systems such as:

- Experience
- Missions
- Achievements
- Seasonal progress
- Statistics
- Collections

Time invested should always have value.

---

# 4. Waiting Must Never Feel Empty

Moments without number matches should still feel engaging.

Whether through presentation, progression, social interaction, anticipation, or dynamic systems, players should remain emotionally invested throughout the match.

Silence should create suspense—not boredom.

---

# 5. Every Feature Must Create Emotion

Every mechanic should intentionally create at least one emotional response.

Examples include:

- Curiosity
- Hope
- Suspense
- Excitement
- Satisfaction
- Relief
- Triumph

If a feature creates no meaningful emotional value, it should not exist.

---

# 6. Simplicity Is Never Sacrificed

The game should remain approachable for players of every experience level.

Complexity should come from layered systems—not confusing rules.

If a mechanic requires lengthy explanations before it becomes enjoyable, it should be redesigned.

---

# 7. Players Must Always Understand Why Something Happened

Outcomes should never feel random without explanation.

Whenever something happens, players should understand:

- What happened.
- Why it happened.
- How it affected the match.

Good feedback builds trust.

Confusion destroys it.

---

# 8. Every Match Should Feel Alive

The game should always feel active.

Players should see:

- Reactions
- Celebrations
- Progress
- Announcements
- Near victories
- Dramatic moments

The match should feel like a shared event rather than isolated players looking at individual cards.

---

# 9. Social Play Is a Core Experience

Playing with others should always feel more rewarding than playing alone.

Features should strengthen friendships, communities, and memorable shared experiences.

Competition should create respect—not toxicity.

---

# 10. Winning Should Feel Special

Victory should never feel routine.

Presentation matters.

Music.

Animation.

Celebration.

Recognition.

The winner should feel genuinely celebrated.

Likewise, other players should enjoy witnessing the victory rather than immediately leaving the match.

---

# 11. Losing Should Never Feel Punishing

Defeat should motivate another match—not frustration.

Players should always feel that they:

- Made progress.
- Experienced memorable moments.
- Improved.
- Came close.
- Have something to look forward to next time.

The game should encourage "One more match."

---

# 12. Design Systems, Not Exceptions

Whenever possible, create reusable systems instead of one-off mechanics.

Instead of building one event,

build an event framework.

Instead of creating one power-up,

build a power-up system.

Good systems make future creativity easier.

---

# 13. Polish Is Never Optional

Animations.

Audio.

Transitions.

Feedback.

Timing.

These are not finishing touches.

They are part of the gameplay experience.

A feature is not complete until it feels complete.

---

# 14. Every New Feature Must Earn Its Place

Features should never be added simply because they are possible.

Every proposal should answer:

- Does it make the game more fun?
- Does it create memorable moments?
- Does it improve the player's experience?
- Does it strengthen the game's identity?

If the answer is "No," it does not belong.

---

# 15. The Game Must Be Built to Last

Short-term convenience must never compromise long-term quality.

Every decision should consider:

- Future expansion.
- Maintainability.
- Consistency.
- Scalability.

The game should continue evolving without losing its identity.

---

# The Final Rule

Whenever uncertainty exists, choose the option that creates the better experience for the player.

Technology can change.

Features can change.

Presentation can change.

The player experience always comes first.

---

# Our Promise

We promise to protect what makes this game special.

We will modernize bingo without losing its identity.

We will prioritize memorable experiences over unnecessary complexity.

We will respect every player's time.

We will build systems that grow naturally.

Most importantly, we will never sacrifice the joy of playing for the convenience of building.

Every decision should move us closer to creating the definitive modern multiplayer bingo experience.
